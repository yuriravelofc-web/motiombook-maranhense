# Motim Book — Do Zero aos 50K

Protótipo interativo responsivo para o Dudu Maranhense.

## Rodar
Abra `index.html` diretamente ou publique a pasta na Vercel.

## Recursos
- Mobile-first / desktop responsivo
- Navegação por capítulos
- Animações de entrada e microinterações
- Checklists com progresso
- Desafio de 7 dias
- Atividades com feedback
- Métricas simuladas
- Passaporte e conquistas
- Progresso local via localStorage
- Menu lateral
- Estrutura pronta para substituir mídia e conectar backend
