Perca o medo da câmera

O segredo não é nascer desinibido. É treinar.

Uma das maiores barreiras para quem quer começar a criar conteúdo é apertar o botão de gravar. Você olha para a câmera e parece que esquece tudo.

Mas existe uma verdade simples: você não precisa perder o medo para começar. Você precisa começar para perder o medo.

Grave mesmo que não publique. Fale sobre qualquer assunto. Depois assista. Você provavelmente vai achar estranho — e está tudo bem.

O treino vem antes da confiança.
